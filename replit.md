# SRP Manhunt Telegram Bot

A Telegram bot for the SRP Manhunt Minecraft server.

## Commands
- `/start` — Welcome message with command list
- `/ip` — Show server IP
- `/rules` — Show server rules
- `/event` — Show current events
- `/status` — Show server status

## Setup
1. Add `TELEGRAM_BOT_TOKEN` as a secret (your bot token from @BotFather)
2. Start the workflow to run the bot

## Configuration
- Server IP is set in `bot.py` via `SERVER_IP`
- Chat/channel link is set via `DISCORD_OR_CHAT`

## User Preferences
- Language: Russian (bot responses are in Russian)
